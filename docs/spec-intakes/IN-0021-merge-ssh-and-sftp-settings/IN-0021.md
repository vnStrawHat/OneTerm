# Spec Intake: Merge the SSH and SFTP settings pages

ID: IN-0021
Date: 2026-09-09
Type: change_request
Lane: normal

## Source

Owner request (2026-09-09): "Merge the SSH and SFTP settings into one." The Settings window
currently lists an "SSH" page (group "Connection": keepalive enabled / interval / max
unanswered) and a separate "SFTP" page (group "Editor": editor mode / program / args, and a
group with the maximum edit file size).

## Requested Outcome

One Settings page titled "SSH" carrying all of the SSH and SFTP options, in this order:

1. `Connection` — unchanged keepalive fields.
2. `SFTP Editor` — the old "Editor" group, described as the SFTP browser's Edit action.
3. `SFTP Edit Limit` — the old file-size group, same field and validation.

The page keeps `IconName::Network` and stays `resettable(true)` so "Reset All" resets all
three groups. The `terminal.json` layout (`ssh` and `sftp` groups in `crates/settings`) is
unchanged: no schema change, no migration.

## Project Impact

- Surfaces: the Settings window sidebar loses its "SFTP" entry; every setting stays reachable.
- Contracts: none. Setting IDs, `default_value`s and the persisted schema are untouched.
- Users: existing `terminal.json` files keep working without migration.
