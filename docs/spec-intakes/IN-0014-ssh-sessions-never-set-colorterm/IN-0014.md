# Spec Intake: SSH sessions never set COLORTERM=truecolor so remote CLIs render wrong colors

ID: IN-0014
Date: 2026-08-24
Type: maintenance
Lane: normal

## Source

Link or summarize the authoritative request, attachment, or external reference.

## Requested Outcome

The SSH connect path in crates/ssh/src/session.rs requests a PTY (TERM=xterm-256color) and a shell but never sends an SSH env request, so the remote shell has no COLORTERM=truecolor. Truecolor-aware remote CLIs fall back to 256 colors and render wrong colors. Local shells already set COLORTERM via base_env(); SSH must match.
