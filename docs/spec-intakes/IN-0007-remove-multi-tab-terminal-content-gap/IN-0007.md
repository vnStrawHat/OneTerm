# Spec Intake: Remove multi-tab terminal content gap

ID: IN-0007
Date: 2026-08-12
Type: maintenance
Lane: tiny

## Source

User bug report with `Screenshot 2026-08-12 140419.png`: when the center `TabPanel` contains two terminal tabs, an empty horizontal band appears between the tab bar and terminal content; the band is absent with one tab.

## Requested Outcome

Remove the extra top padding between the terminal tab bar and terminal content that appears only when a TabPanel contains multiple terminal tabs, while preserving the one-tab layout and existing tab title behavior.

## Project Impact

The center terminal surface is affected only in multi-tab layout. The pinned gpui-component `TabPanel` adds `pt_2()` when there is more than one panel and the active panel returns the default `inner_padding() == true`. Terminal content is already a full-bleed surface and should opt out through the existing `Panel` contract rather than patching the vendored component.
