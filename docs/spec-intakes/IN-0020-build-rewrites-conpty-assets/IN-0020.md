# Spec Intake: Build script rewrites the ConPTY assets on every build

ID: IN-0020
Date: 2026-09-09
Type: bug
Lane: normal

## Source

Owner report (2026-09-09): launching OneTerm shows "cmd.exe - Application Error: The
application was unable to start correctly (0xc0000142)". The same binary starts cleanly when
launched while no build is running. `crates/app/build.rs` copies `conpty.dll` and
`x64/OpenConsole.exe` into the target directory on every build, in place; a launch that races
a rebuild can load a half-written `OpenConsole.exe`, and a console client whose server fails
to start dies with STATUS_DLL_INIT_FAILED.

## Requested Outcome

A rebuild never leaves a partially written runtime asset next to the binary, and unchanged
assets are not rewritten at all.

## Project Impact

- Surfaces: developer builds (`cargo build`, `fast-dev`) on Windows; release packaging reads
  the same files.
- Contracts: the on-disk layout documented in `crates/app/build.rs` is unchanged.
