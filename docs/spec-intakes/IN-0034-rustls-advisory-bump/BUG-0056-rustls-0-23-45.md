## Context

`rustls` is not a workspace dependency. It arrives only through `reqwest 0.12` (feature
`rustls-tls-native-roots`) in `crates/update`, via `hyper-rustls` and `tokio-rustls`. OneTerm's
SSH/SFTP stack is `russh` with the `ring` backend and never links rustls, so the advisory does
not reach any terminal or file-transfer path — only the auto-updater's HTTPS client.

The advisory's own remedy (`>= 0.23.45`) is a patch release inside `^0.23`, which is what every
dependant requires, so step (a) of the fix ladder applies and steps (b) and (c) are not needed.
