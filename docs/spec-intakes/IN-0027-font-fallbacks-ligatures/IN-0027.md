# Spec Intake: Font fallbacks and ligatures

ID: IN-0027
Date: 2026-09-11
Type: new_spec
Lane: normal

## Source

Owner request (2026-09-11): Nerd Font icons in prompts (starship, powerlevel10k) must render
through a fallback font, and font ligatures must work now that the render engine is ours.
Ordered after the owner's ranking: fallbacks first, ligatures second (Sixel graphics is a
separate intake).

## Requested Outcome

1. A configurable list of fallback font families for the terminal. Glyphs the primary font
   lacks (Nerd Font private-use icons, CJK, symbols) come from the first fallback that has
   them, then the system fallback. The default list names the Nerd Font symbol fonts so a
   user who installed one sees prompt icons without touching settings.
2. Ligatures (`calt`/`liga`) render correctly: a ligature glyph spans its cells and the glyphs
   after it stay in their own columns. Ligatures are on by default (the bundled default font
   `Lilex` ships them) with a settings switch to turn them off.

## Project Impact

- Surfaces: terminal grid text; Settings UI > Terminal > Font (two new items);
  `terminal.json` `font` group (two new keys, additive, old files still load).
- Contracts: `FontConfig` / `TerminalSettings` gain `fallbacks` and `ligatures`;
  `RenderInputs::style_key` and the view's cached font must include them so cached plans and
  shaped runs are dropped when they change.
- Users: no behavior change for a user without a Nerd Font installed (DirectWrite skips
  families it cannot find); ligature users no longer see the shifted glyphs that made `calt`
  default off.
- Platforms: `Font::fallbacks` is honored by the DirectWrite text system (Windows); the
  Linux text system ignores it (upstream TODO in `gpui/src/text_system.rs`), where only the
  system fallback applies. Ligature placement is platform-independent (post-layout in
  `gpui/src/text_system/line_layout.rs`).

## Architecture and Boundary Questions

- Runtime and owning boundary: `crates/settings` owns the config; `crates/terminal-view`
  builds the `gpui::Font` and positions glyphs; `crates/settings-ui` exposes the fields.
- Data ownership and lifecycle: two new keys in `terminal.json`; serde defaults keep old
  files valid.
- Auth, security, privacy, or audit: none. Family names are passed to the platform text
  system only.
- External systems and side effects: none.
- Public interfaces and compatibility: `TerminalSettings` is crate-public and gains two fields
  with defaults; `FontConfig` is `serde(default)`.

## Open Decisions and Questions

- [x] Ligatures default on: the default font ships them and the owner asked for them; the
  switch covers users who prefer plain glyphs. No decision record (settings default, not an
  architectural choice).
- [x] Glyph placement stays on top of `force_width` shaping (GPUI keeps within-cell offsets
  for combining marks); only the cell anchor is recomputed from the glyph's byte index.
