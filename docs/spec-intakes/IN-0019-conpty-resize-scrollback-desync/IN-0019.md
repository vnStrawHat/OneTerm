# Spec Intake: ConPTY grow-resize desynchronises grid and conhost

ID: IN-0019
Date: 2026-09-09
Type: bug
Lane: normal

## Source

Owner report (2026-09-09) during acceptance of IN-0018: with the cursor on the last row of the
primary screen, run an alt-screen TUI (`opentui-examples.exe`), maximize the OneTerm window while
it runs, quit the TUI. Back on the primary screen a stale fragment (`opentui-examples.exe` plus a
block cursor) is painted in the middle of the earlier `dir` output and the last prompt row is
clipped. Screenshot kept by the owner (`Screenshot 2026-09-09 084004.png`, not in the repo).

Triage in `docs/spec-intakes/IN-0018-rebuild-terminal-render-engine/US-0049-terminal-view.md`
("Acceptance Rework 2", bug 2) showed the render engine paints exactly what the grid holds; the
same picture appears with the old engine on `main`
(`../IN-0018-rebuild-terminal-render-engine/evidence/rework2-bug2-resize-desync-{new,main}.png`).

## Requested Outcome

After a local (ConPTY) session's viewport grows while the shell or a TUI is running, typed input
and shell output land on the row the shell addresses; no stale rows or cursor fragments remain,
and the prompt is the last visible row.

## Project Impact

- Surfaces: local shells on Windows (ConPTY), window resize/maximize, alt-screen TUIs.
- Contracts: `TerminalModel::resize_grid` / `PtyTransport::pty_resize` ordering
  (`crates/terminal/src/model.rs`, `crates/terminal/src/backend/transport.rs`,
  `crates/local-shell/src/transport.rs`); the vendored `alacritty_terminal`
  `Grid::grow_lines` (`vendor/alacritty_terminal/src/grid/resize.rs:43-69`).
- Not affected: the view crate (`crates/terminal-view`), SSH sessions (remote PTYs reflow on the
  server and repaint).

## Architecture and Boundary Questions

- Runtime and owning boundary: `crates/terminal` (grid resize policy) and `crates/local-shell`
  (ConPTY transport); a vendored-fork patch under `vendor/patches/alacritty_terminal/` is possible
  but must go through `vendor/refresh.sh`.
- Data ownership and lifecycle: scrollback lines pulled into the viewport by `grow_lines`.
- Auth, security, privacy, or audit: none.
- External systems and side effects: conhost/OpenConsole behaviour on `ResizePseudoConsole`.
- Public interfaces and compatibility: `TerminalRender::resize` semantics for local sessions.
