# Spec Intake: Preserve terminal creation entry point

ID: IN-0016
Date: 2026-08-25
Type: change_request
Lane: normal

## Source

User report: after every terminal tab is closed, the terminal tab bar and its `+` menu disappear. A subsequently connected SSH session can also fail to produce a visible tab.

## Requested Outcome

Keep the final terminal tab as a single empty placeholder instead of removing it, so the terminal tab bar and `+` (New Terminal) menu remain available. New local and SSH terminal tabs must still be addable afterward.

## Project Impact

This changes the terminal tab close behavior in `oneterm-terminal-view`. It affects the center dock terminal tab bar, terminal session shutdown, and the empty-Space presentation; it does not change backend session creation or persisted layouts.

## Architecture and Boundary Questions

- Runtime and owning boundary: `TerminalPanel` owns the close policy; `TabPanel` remains generic.
- Data ownership and lifecycle: all sessions in a closed final tab are shut down before its tree is replaced.
- Auth, security, privacy, or audit: no impact.
- External systems and side effects: session shutdown only; no new effects.
- Public interfaces and compatibility: no public API or persistence change.
