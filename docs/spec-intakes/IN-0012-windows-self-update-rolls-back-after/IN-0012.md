## Requested Outcome

On Windows, updating 0.4.0 to 0.4.1 quits the app but never relaunches and keeps the old version. The 0.4.0 helper script added 'if errorlevel 1 goto restore_backup' after start (trips on residual errorlevel from prior xcopy) and xcopy lacks /R so read-only installed files are not overwritten (errorlevel 4 -> rollback).
